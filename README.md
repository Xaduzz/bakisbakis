# NetCentral - Automated Network Configuration Platform

This project is being developed as part of a bachelor's thesis. The system is under active development.

## Features

- SNMP v2c and SNMP v3 support
- SSH access for retrieving device configurations
- Execution of Ansible playbooks from the web interface
- User authentication and role-based access control
- Device status monitoring
- Configuration editor with save and apply functionality
- Action logging (recent activity)

## Technologies Used

Frontend: React.js  
Backend: Python (Flask)  
Database: MySQL  
Automation: Ansible  
Authentication: JWT tokens  
Protocols: SNMP, SSH, ICMP

## Requirements

- Ubuntu 20.04 or newer  
- Python 3.12 or newer  
- Node.js and npm  
- MySQL server  
- Ansible  
- At least 2 GB RAM and 500 MB disk space  
- Stable internet connection
